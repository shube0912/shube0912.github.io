プライバシーポリシー

最終更新日：2026年11月14日

ホーム利用規約

1. 対象

このポリシーは、個人用ツール「bleague-shorts」(以下「本アプリ」)における情報の取り扱いを定めるものです。本アプリは運営者本人だけが利用します。

2. 取得する情報

本アプリが Google アカウントを通じて取得するのは、運営者本人の YouTube チャンネルに動画を投稿するための許可(OAuth のトークン)だけです。氏名、メールアドレス、視聴履歴、連絡先など、それ以外の個人情報は取得しません。第三者の情報は取得しません。

3. 利用目的

取得した許可は、本アプリが作成したショート動画を運営者本人の YouTube チャンネルに投稿する目的にだけ使います(YouTube Data API の動画アップロード機能のみを使用)。

4. 保管と管理

許可(トークン)は、アクセスを制限した保管場所(GitHub の暗号化された Secrets)にのみ保管し、公開しません。広告や分析のために使うことはなく、第三者に販売・提供することもありません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

6. 許可の取り消し

本アプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 変更

このポリシーを変更する場合は、このページで公開します。

English summary

bleague-shorts only requests permission to upload videos to its owner's own YouTube channel (YouTube Data API upload scope). It does not collect any other personal data, does not access other users' data, and does not share or sell any data. The OAuth token is stored only in encrypted GitHub Secrets. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account permissions.
