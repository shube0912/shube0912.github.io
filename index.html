bleague-shorts

バスケットボールの公開スタッツをもとにした「データで見る勝敗予想」ショート動画を作る、個人用のツールです。

プライバシーポリシー利用規約

このアプリでできること

  • 公開されている試合結果・スタッツから、次の試合の勝敗予想を計算します。
  • 予想をまとめた縦型のショート動画を作ります。
  • 作った動画を、運営者本人の YouTube チャンネルに投稿します(YouTube Data API を使用)。

利用者について

このアプリは運営者本人だけが使う個人用のツールです。第三者がログインしたり、第三者の YouTube アカウントにアクセスしたりすることはありません。

English

bleague-shorts is a personal tool that creates short "data-based game prediction" videos from public basketball statistics and uploads them to the owner's own YouTube channel via the YouTube Data API. It is used only by its owner.
